# Types de projets supportés par BriefPilot AI

## Site vitrine

Objectif :
Présenter une entreprise, ses services, ses preuves, et générer des contacts.

Livrables fréquents :
- accueil
- à propos
- services
- réalisations
- témoignages
- contact
- blog optionnel

## E-commerce

Objectif :
Vendre des produits ou services en ligne.

Livrables fréquents :
- catalogue
- fiche produit
- panier
- paiement
- livraison
- compte client
- emails transactionnels

## SaaS

Objectif :
Fournir une application web avec comptes utilisateurs, dashboard, abonnement et fonctionnalités métier.

Livrables fréquents :
- auth
- dashboard
- gestion projets/données
- rôles
- paiement
- notifications
- analytics

## Application mobile

Objectif :
Fournir une expérience iOS/Android.

Livrables fréquents :
- onboarding
- auth
- écrans métier
- notifications push
- stockage local
- API backend

## ERP / outil interne

Objectif :
Digitaliser un processus métier.

Livrables fréquents :
- rôles utilisateurs
- workflows
- tableaux de bord
- validations
- exports
- permissions
- historique
