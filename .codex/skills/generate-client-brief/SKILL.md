# Skill: Generate Client Brief

## Objectif

Ce skill transforme une demande client vague en brief projet professionnel et exploitable.

BriefPilot AI doit aider à produire :

- un cahier des charges clair
- les objectifs business
- les utilisateurs cibles
- les pages ou écrans
- les fonctionnalités
- les contenus nécessaires
- les intégrations
- les contraintes
- les informations manquantes
- les questions à poser au client
- une estimation
- un backlog initial

## Quand utiliser ce skill

Utiliser ce skill quand la tâche demande de :

- transformer une conversation client en brief
- générer un cahier des charges
- analyser un besoin client
- structurer une idée de projet
- trouver les informations manquantes
- produire une version client et une version technique

## Processus obligatoire

1. Identifier le type de projet :
   - site vitrine
   - e-commerce
   - SaaS
   - application mobile
   - ERP / outil interne
   - automatisation métier
   - autre

2. Extraire les informations connues :
   - contexte
   - objectifs
   - cible
   - fonctionnalités
   - budget
   - délai
   - contraintes
   - contenus disponibles

3. Identifier les informations manquantes.

4. Ne jamais inventer les informations critiques.

5. Si une hypothèse est nécessaire, la marquer clairement comme hypothèse.

6. Produire deux niveaux de lecture :
   - version claire pour client non technique
   - version technique pour développeur

## Structure de sortie attendue

Le brief doit contenir :

1. Résumé du projet
2. Contexte
3. Objectifs business
4. Cibles utilisateurs
5. Problème à résoudre
6. Fonctionnalités principales
7. Fonctionnalités secondaires
8. Pages ou écrans
9. Rôles utilisateurs
10. Parcours utilisateur
11. Contenus nécessaires
12. Intégrations
13. Contraintes techniques
14. Contraintes sécurité
15. Contraintes légales éventuelles
16. Informations manquantes
17. Questions à poser au client
18. Risques projet
19. Planning estimatif
20. Budget estimatif
21. Critères de validation
22. Backlog initial

## Règles importantes

- Ne pas halluciner les besoins.
- Toujours distinguer les faits des hypothèses.
- Toujours lister les zones floues.
- Toujours proposer les prochaines questions utiles.
- Garder un ton professionnel, clair et exploitable.
